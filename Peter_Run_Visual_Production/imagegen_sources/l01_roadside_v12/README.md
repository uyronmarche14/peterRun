# L01 v12 passing-street source art

Archived after the fixed-street clarification: these whole-building sprites and clean-road masks remain available as source work, but they are not used by the active L01 scene. The game now keeps its registered V10/V11 buildings and road fixed, with small stage-specific `StreetLife` overlays for local motion.

These five transparent source images were generated as original, isolated 2.5D illustrations. They are source art, not Godot runtime textures. `code/tools/export_l01_v12_roadside_sprites.gd` places each subject on a common 512 x 512 transparent canvas with a stable bottom-contact anchor. Runtime art lives in `code/art/backgrounds/l01_roadside_v12/`.

The image-generation prompt set used one subject per image:

- `home_veranda_source.png`: modest Filipino barangay veranda home with sawali wall panels, capiz-inspired windows, coral bougainvillea, cream fence, teal pitched roof, in warm morning light.
- `waiting_shed_source.png`: friendly barangay waiting shed with teal roof, bamboo/wood posts, bench, two potted plants, and blank notice frame.
- `sari_sari_source.png`: two-storey sari-sari shop with painted concrete, teal/coral awning, colorful shelves, baskets, and pots.
- `market_stall_source.png`: palengke produce stall with timber, woven baskets, vegetables, teal/mango canopy, and warm lamps.
- `plaza_kiosk_source.png`: shaded community-garden kiosk with cream columns, teal roof, lanterns, flowers, and benches.

Shared prompt constraints: transparent RGBA background; entire compact structure in frame; consistent ground contact; elevated road-facing runner perspective; crisp low-poly/illustrated 2.5D finish matching the approved journey plates; no road, curb, sidewalk, people, text, UI, or watermark. Existing V09 journey plates were used only as style references, not copied into the new sprites.

`code/tools/export_l01_v12_clean_roads.gd` derives each registered road from the V09 stage plate while masking baked-in sidewalk subjects. The passing-street manifest keeps decorative structures outside the painted curb. The distant skyline and Barangay Hall remain fixed as the visual destination; only the near roadside subjects travel past Peter.

Validation screenshots and pause/reduced-motion evidence are generated by `code/tests/support/capture_l01_v12_passing_street.gd` into `test_evidence/l01_v12_passing_street/`.
