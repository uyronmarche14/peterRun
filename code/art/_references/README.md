# ComfyUI Reference Area — Not Runtime Art

This directory stores original visual references only.

- Put L01 reference renders in `l01_barangay/`.
- Put matching prompt text in `comfyui_prompts/`.
- Put exported ComfyUI workflow JSON in `comfyui_workflows/`.
- Keep model name/version, seed, workflow, prompt, source licence, and approval status together.
- Do not link these raw images from Godot scenes or level resources.

Approved ideas move through Krita and Pixelorama before final PNGs are placed in runtime `art/` folders.
