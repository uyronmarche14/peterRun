# 3 · Setting up and running a session

> 👩‍⚕️ For the therapist or guardian. The game is **supervised**: you choose the plan, the patient does it, and you look at the result together.

## ✅ Before the session

1. Start the game. The welcome screen shows **Start Session**, **Tutorial**, **Settings** and **Quit**.
2. *Optional:* **Settings → Check controller** to confirm the keyboard or controller works. See [Controls](7-controls-sensitivity-and-delay.md).
3. *Optional:* run the **Tutorial** so the patient can try each movement first.

## 🧩 Setting up

Choose **Start Session**. The setup screen has:

| Setting | What it does |
| --- | --- |
| **Route** | Currently **Barangay Morning**. |
| **Repetitions per movement** | Use the **−** and **+** buttons: **1 to 50** for each of Move Left, Move Right, Jump and Slide. The default is 10 each (40 in total). |
| **Game speed** | **1 to 10**. The screen opens on **6, the standard speed**. A lower number is faster, a higher number slower. See [Game speed](6-game-speed.md). |
| **Test controls / Practice movements** | Optional extras. |

Press **Review session** to continue.

## 🟢 The Ready screen

*"Ready when you are."* It repeats the plan, including the game speed. From here you can test controls, practise, **Edit session**, or press **Start Session**. Nothing starts until you press Start.

## ▶️ During the session

- The patient sees **one instruction at a time**. Each takes about 5 seconds: a **GET READY** warning (1.5 to 4 seconds, by game speed), **2 seconds** to respond, and a short settle.
- **The 2-second response window never changes.**
- **Pause** (`P` or the on-screen button) freezes the game at once. From there you can resume, **End Level** or **End Session**. Ending asks for confirmation and carries no penalty.
- A repetition counts only for the **right movement in the right lane**. A wrong or missing response is a *neutral miss*: it is noted, it is not scored against the patient, and the next obstacle is made easier.

### 🛑 What ends a run

| Reason | What the patient sees |
| --- | --- |
| All planned repetitions done | "Level complete" |
| Peter reaches an obstacle | "Run ended. Peter reached an obstacle. Completed repetitions are saved for review." |
| You end the level or session | "Level ended" / "Session ended" |

Ending on contact is intentional. There are no lives, health, score loss or chase. Completed repetitions are always kept.

## 📊 Reading the review

The review screen shows, for each movement, **completed / planned** (for example *Jump: 8 / 10*). Then choose together:

| Button | Meaning |
| --- | --- |
| **Rest** | Take a break. Nothing starts by itself. |
| **Retry** | Same plan again. Available **after a speed (1 to 10) is chosen**. |
| **Finish** | Return to the welcome screen. If no speed was chosen it says **Finish without choosing**. |

## ⚙️ Settings that may help

Under **Settings**: music on or off and volume, scenery motion, contact-effect strength, **Reduced motion**, and the **start countdown** (3 s, 5 s or off). The input **sensitivity** and **delay test** are on the **Check controller** screen.

## 📝 Good to know

- The game records what the patient did against your plan. It does not measure angles or diagnose.
- Each time you leave the review with **Retry** or **Finish**, the game adds one line of numbers to a private **session history** file on the computer: the time, route, how the run ended, repetitions done and planned, and the speed chosen. It stores **no names or personal details**. No screen shows it yet.
- Note anything you need for your own records before closing the game.

> ⚠️ **Needs your approval before patient use:** a game speed of 1 to 5 shortens the GET READY warning (down to 1.5 s), and **High** input sensitivity allows quicker repeats. The 2-second response window is never changed.
