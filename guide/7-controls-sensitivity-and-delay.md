# 7 · Controls, sensitivity and delay

## 🎹 Controls

Keyboard, gamepad and the MOVE controller all do the same five things, so the game behaves the same with any of them.

| Action | Keyboard | Gamepad |
| --- | --- | --- |
| Move left | `A` or ← | D-pad left |
| Move right | `D` or → | D-pad right |
| Jump | `W` or ↑ | Bottom face button (Xbox **A**, PlayStation **Cross**) |
| Slide | `S` or ↓ | Right face button (Xbox **B**, PlayStation **Circle**) |
| Pause | `P` | Start / Options / + |

> 🖱️ **Menus use the mouse.** The movement keys do not move around menus.

> 🧪 **The MOVE controller** is a wearable that acts like a keyboard. It must be tested separately before clinical use. Until then, use the keyboard.

## 🔎 Check your controls

1. Open **Settings → Check controller** (also offered as **Test controls** in setup and on the Ready screen).
2. Press each movement once. A tile turns **green** when it is detected.
3. When all five are green, continue.

## 🎚️ Sensitivity

On the **Check controller** screen there is a **Sensitivity** choice. It decides how quickly the same button may be pressed again, and how far a gamepad stick must be pushed.

| Setting | Same button again after | Stick must be pushed | Use it when |
| --- | --- | --- | --- |
| **Low** (steady) | 0.50 s | 65% | One press is being counted twice |
| **Normal** (default) | 0.35 s | 50% | Most of the time |
| **High** (quick) | 0.15 s | 35% | Presses are being missed |

It is remembered the next time the game opens. If a press is ignored, the screen says why: **too soon after the last press**, or **the button is still held**.

> ⚠️ **High** allows faster repeats. Please have a clinician approve it before patient use.

## ⏱️ Delay test

The delay test shows how long it takes from a signal to a press.

1. Press **Delay test**.
2. Wait. The message changes to **Press NOW**.
3. Press any action. The screen shows the time in milliseconds, the average of the last five, and the best.

If you press too early, it says *"That was early. Wait for the cue."* and starts again.

> 💡 **To find the controller's own delay**, run the test once on the keyboard and once on the MOVE controller. The difference is the controller. The result includes the player's reaction, so compare many presses, not one.

## 🛠️ If something is wrong

| Problem | Try this |
| --- | --- |
| A movement does nothing | Run **Check controller**. If the tile never turns green, that button is not reaching the game. |
| Peter moved twice | Release the button fully between presses, or choose **Low** sensitivity. |
| Presses are missed | Choose **High** sensitivity (with clinical approval) or press again after releasing. |
| The controller feels slow | Run the **Delay test** on the keyboard and on the controller and compare. |
| Gamepad not found | Connect it before opening the game, then open **Check controller**. |
| Pause did nothing | The run may already be over. Pause works only during play. |
