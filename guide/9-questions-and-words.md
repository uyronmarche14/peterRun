# 9 · Questions and words

## ❓ Common questions

<details>
<summary><b>Is there a score, lives or a timer for the whole level?</b></summary>

No. There are no lives, health, score or leaderboard. The goal is to finish the planned repetitions at a calm pace.
</details>

<details>
<summary><b>Does the game speed up while I play?</b></summary>

No. The time to respond is always **2 seconds**. You can choose a **game speed** from 1 to 10 before a run. It changes the scenery and how long the **GET READY** warning lasts, nothing else. See [Game speed](6-game-speed.md).
</details>

<details>
<summary><b>What happens if I touch an obstacle?</b></summary>

The run ends and the review opens. Everything you completed is saved. It is not a penalty; it is a clear stopping point to look at with your therapist.
</details>

<details>
<summary><b>What if I press the wrong movement, or nothing?</b></summary>

It is a *neutral miss*: no penalty and no negative message. The next obstacle is made easier. If Peter is left in a lane with an obstacle, the run ends.
</details>

<details>
<summary><b>What is "Path is clear."?</b></summary>

For some obstacles, if Peter is already in a safe lane when the time runs out, nothing needed doing. It is a safe pass and is not counted as a repetition.
</details>

<details>
<summary><b>Why does Left always mean left?</b></summary>

So the controls stay predictable. The game no longer asks which side is affected, and it never swaps left and right.
</details>

<details>
<summary><b>Can I stop whenever I want?</b></summary>

Yes. Press `P` to pause, then choose **End Level** or **End Session**. You are asked to confirm. There is no penalty.
</details>

<details>
<summary><b>How many repetitions can be set?</b></summary>

From **1 to 50** for each of the four movements (4 to 200 in total). The default is 10 each.
</details>

<details>
<summary><b>Which game speed should I use?</b></summary>

Start on **6** (standard). Go lower (faster) if it feels too easy, higher (slower) if it feels rushed. A therapist should approve speeds 1 to 5 before patient use, because the warning is shorter.
</details>

<details>
<summary><b>Why is only one route offered?</b></summary>

Only **Barangay Morning** is shown in setup. **Market Morning** and **Rainy Crossing** are built but hidden for now.
</details>

<details>
<summary><b>Are my results saved?</b></summary>

For the review and Retry, results are kept while the game is open. When you leave the review with **Retry** or **Finish**, the game also adds one line of numbers to a private history file on the computer: the time, route, how the run ended, repetitions done and planned, and the speed chosen. It stores no names or personal details.
</details>

<details>
<summary><b>Can I practise first?</b></summary>

Yes. Use **Tutorial** on the welcome screen, or **Practice movements** in setup and on the Ready screen.
</details>

<details>
<summary><b>Which controllers work?</b></summary>

Keyboard, a standard gamepad, and the MOVE controller when it sends the same keys. See [Controls](7-controls-sensitivity-and-delay.md).
</details>

<details>
<summary><b>Does the game speak Filipino?</b></summary>

The setting and the music are Filipino (*Barangay Morning*, *Hakbang sa Umaga*) and the welcome screen says *Bawat hakbang ng buhay*. The words on screen are currently in English.
</details>

<details>
<summary><b>Is it a medical device?</b></summary>

No. It is a supervised practice aid. It does not diagnose or treat, and it does not replace a therapist's judgement.
</details>

## 📖 Words used in the game

| Word | Meaning |
| --- | --- |
| **Barangay** | A Filipino neighbourhood. The route is *Barangay Morning*. |
| **Repetition (rep)** | One correct response. The target is set per movement, from 1 to 50. |
| **Movement** | One of Move Left, Move Right, Jump, Slide. **Pause** is a control, not a movement. |
| **Lane** | One of the three paths on the road (left, middle, right). |
| **Obstacle** | A crate, puddle or laundry line that asks for a movement. |
| **Arrangement** | One planned layout of obstacles across the lanes, together with the movement that solves it. |
| **Instruction (prompt)** | What the screen asks for now. Only one at a time. |
| **GET READY** | The warning before the response window. |
| **MOVE NOW** | The 2-second response window. |
| **Neutral miss** | An answer that was not right and caused no contact. No penalty; the next obstacle is easier. |
| **Path is clear** | The player was already safe, so nothing was needed. Not counted as a repetition. |
| **Contact** | Peter ending in a lane that has an obstacle. It ends the run; completed work is kept. |
| **Game speed** | A number from 1 (faster) to 10 (slower). See [Game speed](6-game-speed.md). |
| **Sensitivity** | How soon a button may repeat, and how far a stick must move. Low, Normal or High. |
| **Delay test** | A short test showing the time from a signal to a press. |
| **Session** | One supervised play-through, from setup to review. |
| **Review** | The screen at the end with what was done and the speed choice. |
| **MOVE controller** | A planned wearable that sends keyboard presses. |
| **2.5D** | A flat game that looks like forward travel by using layers and perspective. There is no real 3D. |
