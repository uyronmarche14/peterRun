# FAQ

**Is there a score, lives, or a timer for the whole level?**
No. There are no lives, health, score or leaderboard. The goal is to complete the planned repetitions at a calm pace.

**Does the game speed up?**
The response time never changes (2 seconds). Difficulty comes from how many repetitions the therapist sets. You can choose a game speed from 1 to 10: it changes the scenery and how long the GET READY warning lasts, nothing else (see "game speed" below).

**What happens if I touch an obstacle?**
The run ends and the review opens. Everything you completed is saved. It is not a penalty; it is a clear stopping point to review with your therapist.

**What if I press the wrong movement or nothing?**
It is counted as a *neutral miss*. No penalty, no negative message. The next obstacle is made easier. If Peter is left in a lane with an obstacle, the run ends (see above).

**What is "Path is clear."?**
For some obstacles, if Peter is already in a safe lane when time runs out, nothing needed doing. It is a safe pass and is not counted as a repetition.

**Why does Left always mean left, whichever leg is being exercised?**
So controls stay predictable. The game no longer asks for an affected side.

**Can I stop whenever I want?**
Yes. Press `P` to pause, then choose **End Level** or **End Session**. You will be asked to confirm. There is no penalty.

**What is the 1–10 game speed choice?**
You choose a number from 1 to 10 in Session Setup, and again at the end of a run for the next run: **1 = faster, 10 = slower**. It changes the road and scenery, Peter's stride, and how long the GET READY warning lasts (1.5 s at 1, 2.5 s at standard, 4.0 s at 10). The 2-second response time does not change. You must choose one before using **Retry**, but you can **Finish without choosing**. See [Game Speed](../explainers/game-speed.md).

**How many repetitions can be set?**
1 to 15 for each of the four movements (4–60 total). The default is 10 each.

**Why is only one route available?**
Only **Barangay Morning** is offered in Setup. **L02 Market Morning** and **L03 Rainy Crossing** exist in the game data but are hidden for now.

**Are my results saved?**
Results are kept while the application is open for the review and retry flow. The game does not currently write a patient record, so note what you need before closing.

**Can I practice first?**
Yes. Use **Tutorial** on the opening screen or **Practice movements** during Setup and Ready.

**Which controller does it support?**
Keyboard, a standard gamepad, and the MOVE controller when its firmware sends the same keys. See [Controls](controls.md).

**Does it work in Filipino?**
The setting and music are Filipino (Barangay Morning, *Hakbang sa Umaga*) and the opening shows *Bawat hakbang ng buhay*. Game text is currently in English.

**Is it a medical device?**
No. It is a supervised practice aid. It does not diagnose, treat, or replace a therapist's judgement.
